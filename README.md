# スタンスメモ 独立試作版

公開URL： https://kanon6343.github.io/snowboard-stance-memo-trial/

正式版の /snowboard-stance-memo/ に含まれない場所で試作をインストールできるようにするコピーです。既存の正式版・試作版は変更せずに残します。v2.1.5（試作）、キャッシュ更新1077。

## 公開

このフォルダの中身を新規リポジトリ snowboard-stance-memo-trial のルートへ配置し、GitHub Pages を main ブランチの / (root) から公開します。URLは公開後に検証します。

## データ

同一ブラウザー・同一オリジンであれば haru-detail: の既存データを参照します。別ブラウザーや別ストレージ環境には自動同期しません。既存の試作版でバックアップを書き出しておくと、必要に応じて新しいアプリで復元できます。公開先の分離だけでは同一オリジンのデータ領域は完全には分離されません。

## インストール

新しい試作URLをブラウザーで開き、オフライン準備の完了後、インストール／ホーム画面へ追加します。正式版とはアプリの範囲を重ねない構成です。端末ごとの実機確認は別途行います。

## スタンス幅の検索

「探す」のスタンス幅は「ぴったり／範囲」で切り替えます。ぴったりは53など1つの数値を指定し、53.0は53と同じ幅として扱います。空欄は条件なし。範囲は従来どおり下限・上限を含みます。以前保存した範囲条件は範囲として引き継ぎます。簡易・詳細入力の両方で使え、検索は履歴本体を変更しません。

詳細入力の「探す」では、板の形状（シェイプ・ノーズ形状・ベンド）を折りたたまず常時表示します。簡易入力では非表示です。

更新時は画面HTMLもHTTPキャッシュの再検証を行ってからオフライン用に保存し、連続更新で古い画面が新しいキャッシュに残ることを防ぎます。

## 更新先の表示

更新待ちのService Workerへ直接問い合わせ、更新先の版番号を通知と更新ボタンに表示します。取得できない旧形式の更新は、版番号を推測せず通常の更新ボタンを表示します。今回の機能を読み込んだ後の更新から利用できます。
